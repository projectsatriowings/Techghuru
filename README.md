# Tech Ghuru website prototype

A responsive Next.js App Router frontend built with React 19, TypeScript, and Tailwind CSS 4. The pages are UI prototypes and use illustrative CSS artwork in place of final photography. Forms and booking are front-end demonstrations; connect them to your own backend when ready.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

The route layouts cover the home, studio, contact, features, services, five service pages, consultation, journal, six journal topics, portfolio, and quote request pages.
